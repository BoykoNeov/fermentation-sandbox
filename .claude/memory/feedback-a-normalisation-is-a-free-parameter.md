Two traps, one beat (D-205, the sotolon pH/ethanol refusal).

**1. "The model has both quantities, so it is a real omission rather than an inexpressible one"
is NOT a buildability claim.** That sentence rode ten records as if it meant *buildable*. It only
means the state vector carries the inputs. **Expressible is not identifiable.** Ask what would
*fix* the term, not what it could read.

**2. A term written as a ratio smuggles in a second parameter: its REFERENCE.** `rate ×
([H⁺]/[H⁺]_ref)^n` looks like one unknown (the order `n`). It is two. The reference is normally
waved through as "absorbed into the recalibrated rate constant" — but that only works if the rate
constant was calibrated *somewhere*. Here `k_sotolon_aldol` was fitted with **no pH term at all**,
so there was no reference to recover, and `pH_ref` 3.4 vs 3.0 — both equally defensible — moved the
whole curve 2.51× and reported **two oxidised wines or none**. The reference flipped a sensory
verdict by itself, with the mechanism and the order held fixed.

**Why:** a refusal is only as strong as the parameter you can name. I first framed this as "rival
mechanisms disagree, so nothing adjudicates" — then measured it and the two rival forms (acid
catalysis in [H⁺]; the undissociated-acid fraction) **agreed within 17 %**. The mechanism choice
was nearly free and the real indeterminacy was one level up, in a quantity I had not been counting
as a parameter. Had I shipped the first framing, the record would have argued the wrong point and
a reader could have refuted it in one probe.

**How to apply:** before refusing *or* building a rate-law term, (a) count the reference/
normalisation as a parameter and ask what calibration fixes it — if the constant it folds into was
never fitted against that axis, nothing does; (b) price the RIVAL form too, and if the rivals agree,
say so and look upstream for the free quantity; (c) state whether the crossing value is computed,
and when it is not, say what computing it would require — for a blocked half, that is usually the
very constant whose absence is the block. Pairs with
[[feedback-count-the-anchors-before-adding-a-parameter]] (count observables vs parameters) and
[[feedback-same-species-different-reaction]] (an existing path with the right sign may be a
different reaction and no substitute).
