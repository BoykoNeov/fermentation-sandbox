name: an-always-agreeing-landmark-is-not-evidence
description: "A data landmark the model matches at every parameter value carries no information — never count it as a point of agreement"
metadata:
  node_type: memory

Crepin gives three nitrogen landmarks. The model matched the third (99.1 % of final biomass at
exhaustion) at r = 1 and at r = 1000 alike, because near-complete consumption and near-peak
biomass are the SAME EVENT in a nitrogen-limited run. Writing "one knob lands the triple" would
have been an overclaim: only two landmarks could have been missed, and only those two discriminate.

**Why:** a fit's credibility is the number of ways it could have failed and did not. A landmark
that is structurally forced agrees whatever the model does, so including it inflates the apparent
evidence without adding any.

**How to apply:** sweep the parameter and look at each anchor's SPREAD across the sweep. Zero
spread = zero information; say so in the record and count the anchor out. Pin the
non-discrimination as its own test so a later beat cannot re-import it as support.
