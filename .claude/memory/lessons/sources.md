**Lessons — Sources, literature & transcription.** Split out of `.claude/memory/MEMORY.md` on 2026-08-26; that file's
index points here by path. These rows carry **no `MEMORY.md` row of their own**, so they cost
nothing until this file is read — the same arrangement `prohibitions/` has had since D-185.

**Read this file before you write the code, not after the review.** Each row is *the trap* +
*what to do instead*; the measurement that earned it is in the linked file. If a row looks
like pedantry, open its file — every one of them cost a beat.

- ["Paywalled" is one host, not a paper](../feedback-paywalled-is-one-host.md) — check author/institutional/thesis/trade-reprint copies — and a standards body's OWN site — before recording a source as blocked; wrong 6× so far
- [Re-read the source you already mined](../feedback-re-read-the-source-you-already-mined.md) — D-179 took Tyrell's table and stopped; the same PDF's trial FIGURES held the wort levels, the matching pH curve and the divisor that unblocked D-180. Re-read local sources in FULL before recording a block
- [A text screen has units and self-reference](../feedback-a-text-screen-has-units-and-self-reference.md) — "is my number in the text" missed every J/mol-vs-kJ/mol hit (14→42) and scored notes that quote their own invented edge as sourced; 14 of 42 hits died on reading
- [A note can state its span twice](../feedback-a-note-can-state-its-span-twice.md) — one note gave its band as both kJ/mol and a Q10; converted they were near-disjoint, so "move it to its cited range" was ill-posed. Cross-check a note against itself
- [Transcribe tables, not prose](../feedback-transcribe-tables-not-prose.md) — the table beat the prose twice (4 numbers, then a direction); a search summary once shipped a fabricated E_a
- [A notes field is unchecked storage](../feedback-a-notes-field-is-unchecked-storage.md) — 3 wrong numbers in one beat, all in prose; re-open the source, test against PUBLISHED literals
- [Same species, different reaction](../feedback-same-species-different-reaction.md) — the "species wasn't detected" passage was about a DIFFERENT limb (index p.327-8 vs p.332), one the model already declined; a negative carries a scope the name doesn't. Silent ≠ negative (D-198)
- [A named pull may not answer the question](../feedback-a-named-pull-may-not-answer-the-question.md) — "blocked pending <paper>" also asserts the paper CAN close it; it was on disk and still couldn't. Name what X measures
- [Agreement can be a frame difference](../feedback-agreement-can-be-a-frame-difference.md) — a published pH is DECARBONATED; read the cited method's scope line, name the 2nd frame rather than deleting the term
- [A units fork is not a band](../feedback-a-units-fork-is-not-a-band.md) — I crossed two readings of one printed row into a 12-cell "band" whose whole spread WAS the fork, so the nominal was a midpoint no reading supports. A neighbouring row settled it; ship one reading, name the loser in the note (D-209)
- [Two measurements, one figure, can disagree](../feedback-two-measurements-one-figure-can-disagree.md) — the other series from the same paper admitted only +6 to +14; solve what other observables admit first
- [Right number, wrong condition](../feedback-right-number-wrong-condition.md) — "nothing supports 5-7 days" shipped twice as unconditional, off panels that AVERAGED over temperature; name which half died, bracket rather than interpolate
- [A transcription answers more than its purpose](../feedback-a-transcription-answers-more-than-its-purpose.md) — a table mined for its RATIOS still holds its TOTAL; D-222 called a quantity unsourced for 8 records while D-209's own transcription sized it. Grep your repo's tables before recording a block
- [Check whose fit the other side is](../feedback-check-whose-fit-the-other-side-is.md) — I called a 2x disagreement "two trials"; one side was THIS repo's typo-corrected fit of the other's figure, and "10.06" is nowhere in his text. Grep the source for the number before pairing
