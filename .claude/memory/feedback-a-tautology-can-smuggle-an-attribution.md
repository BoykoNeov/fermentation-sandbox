D-195 conceded that a mutation's re-anchor held total production fixed only on one must, then
wrote: *"the real-data benchmark result is independent of that — a secant outside a measured band
is a data disagreement either way."* That sentence **sounds** like a tautology and is doing no
such work: it asserts that the failure is attributable to the **shape** rather than to the
**magnitude**, which nothing had measured. It was the only unmeasured claim carrying weight in
the verdict, and it was sitting in the paragraph labelled *honesty notes*.

**Why:** conceding a caveat and then declaring it non-binding is how an attribution gets laundered
into a fact — the concession itself reads as rigour, so the sentence after it is not re-examined.
This is [[feedback-conceded-caveats-are-not-coverage]] one turn later: naming the gap does not
discharge it, and neither does asserting the gap doesn't matter.

**How to apply:** run the same-sized move **without** the mechanism
([[feedback-pair-the-red-with-an-ordering-preserving-baseline]]). Here: keep the shipped shape and
collapse the residual by the factor the mutation collapses it. Result — the two arms landed at
**1.100510** and **1.100501**, six figures apart, same tests failing. The shape did nothing; the
**residual** did all of it.

**Measuring it made the conclusion stronger.** The shape framing invited an obvious rescue ("find a
variant with kinder timing"); the measured framing closes it (draining that residual by *any* route
leaves the band) and converts the finding from a fact about a rejected variant into a fact about
**what ships** — that pool's residual is load-bearing for agreement with real measured data, which
nothing in the archive had established. Expect the discriminator to sharpen the claim, not
threaten it, and run it before shipping the sentence. (D-195)
