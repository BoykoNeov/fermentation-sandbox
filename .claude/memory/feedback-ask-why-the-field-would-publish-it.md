Before spending a beat hunting a number the literature "must" contain, ask **what conclusion a
paper would have needed it for**. If no standard endpoint requires the two quantities *together*,
the gap is structural and searching harder cannot close it.

D-271 hunted D-219's open item — a yeast cell COUNT paired with a gravimetric DRY WEIGHT in one
ferment at one timepoint. Four sources, four different misses, and the pattern was not luck:
**each paper reports the one currency its own endpoint needs, and never both.** Crépin weighs and
never counts; Varela counts the inoculum and weighs the crop (two timepoints); Foster counts, and
weighs only to express trehalose per gram; Tyrell counts and pitches by count. The pairing is
nobody's result, so nobody publishes it.

**Why:** "we have not found it yet" and "it is not published" are different states and only one of
them justifies more searching. Two of D-271's four instances were **already recorded at D-219** and
were re-derived before the archive was re-read — the hunt paid twice for the same negative.

**How to apply:** state the mechanism of the absence, not the count of files searched — a negative
with a reason is a durable finding and a file count is not. Check the one place the pairing would
be *routine* before declaring it absent (for cells-per-gram that is quantitative-physiology
chemostat work, which turned out to work in C-mol and not count cells at all). Then write the
negative down as data a future guard can trip on: D-271's four sources are a table where a row with
both flags true turns a test RED, so a later find cannot land silently.
